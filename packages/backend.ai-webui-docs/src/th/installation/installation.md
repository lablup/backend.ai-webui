# การติดตั้ง

Backend.AI WebUI สามารถใช้งานได้ในสองรูปแบบที่แตกต่างกัน
สามารถใช้เป็นบริการบนเว็บได้โดยการเชื่อมต่อไปยังที่อยู่เว็บแยกต่างหากที่ผู้ดูแลระบบจัดเตรียมไว้
หรือในรูปแบบของแอปที่ให้บริการเป็นไฟล์ปฏิบัติการแบบสแตนด์อโลนซึ่งไม่ต้องการการติดตั้งแยกต่างหาก

ในรูปแบบเว็บของ WebUI ผู้ใช้เพียงต้องการเว็บเบราว์เซอร์เวอร์ชันล่าสุดเท่านั้น โดยไม่จำเป็นต้องติดตั้งแอปพลิเคชันเดสก์ท็อปที่ขึ้นกับแพลตฟอร์ม

- เบราว์เซอร์ที่รองรับ: Chrome 123 ขึ้นไป, Edge 123 ขึ้นไป, Safari 17.5 ขึ้นไป, Firefox 125 ขึ้นไป
- ข้อกำหนด: เครื่องใด ๆ ที่สามารถรันเว็บเบราว์เซอร์ได้ (2 คอร์, หน่วยความจำ 4 GiB)


:::note
หากเปิด WebUI ด้วยเบราว์เซอร์ที่เก่ากว่าเวอร์ชันที่รองรับ หน้าจอการโหลดจะแสดงข้อความว่าไม่รองรับเบราว์เซอร์นี้ พร้อมรายการเบราว์เซอร์ที่รองรับ และ WebUI จะไม่โหลด โปรดอัปเดตเบราว์เซอร์หรือใช้เบราว์เซอร์ที่รองรับ หากต้องการใช้ WebUI ในเบราว์เซอร์นั้นต่อ ให้คลิก **Use anyway** ใต้ข้อความ แล้วคลิก **Continue** ในกล่องโต้ตอบยืนยัน ระบบไม่รับประกันการทำงานตามปกติ และข้อความจะแสดงอีกครั้งเมื่อเปิดในแท็บใหม่หรือหลังจากออกจากระบบ

เราไม่รองรับ Microsoft Internet Explorer เนื่องจากถูกยกเลิกการใช้งานแล้วและไม่รองรับคุณสมบัติของเบราว์เซอร์ที่ทันสมัย

แอป WebUI แบบสแตนด์อโลนมีเอนจินเบราว์เซอร์ในตัว จึงไม่อยู่ภายใต้การตรวจสอบนี้
:::

แอป WebUI แบบสแตนด์อโลนสามารถดาวน์โหลดได้จากลิงก์ต่อไปนี้:
https://github.com/lablup/backend.ai-webui/releases


:::note
ขึ้นอยู่กับการตั้งค่าความปลอดภัยของระบบปฏิบัติการ ตัวติดตั้งของเราอาจถูกระบุว่าเป็นไฟล์ปฏิบัติการที่ไม่ได้ลงนาม อาจจำเป็นต้องมีการตรวจสอบสิทธิ์
:::
