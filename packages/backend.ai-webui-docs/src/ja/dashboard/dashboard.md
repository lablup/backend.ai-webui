# ダッシュボード

**ダッシュボード**は、ログイン後に最初に表示されるページで、複数のカードで構成されています。上部のカードは、最初によく行う操作にすぐ移動できるショートカットです。各カードには操作名と一文の説明、その操作を開始するボタンがあります。

- **インタラクティブセッション開始:**
    **セッション開始**をクリックするとセッションランチャーが開きます。環境とリソースを選び、コードを対話的に実行できます。

- **バッチセッション開始:**
    **セッション開始**をクリックすると、セッションタイプがバッチに設定されたセッションランチャーが開きます。入力したコマンドを最後まで自動で実行するセッションを作成するときに使います。

- **保存フォルダー作成:**
    **フォルダー作成**をクリックすると、セッションで使うファイルやデータを保存するストレージフォルダーを作成できます。

- **デプロイ開始:**
    **デプロイを作成**をクリックすると、学習済みモデルを他のユーザーが利用できるよう提供するデプロイを作成できます。このカードは、管理者がモデルサービングを有効にしている場合にのみ表示されます。

- **URLから開始:**
    **今すぐ始めましょう**をクリックし、Jupyter ノートブック、GitHub または GitLab リポジトリ、Hugging Face モデルの URL を入力すると、その内容でセッションを開始できます。

![](../images/dashboard.png)

その下のカードは、現在のプロジェクトのセッション、リソース使用状況、最近のアクティビティを表示します：

- **私のセッション:**
    現在のプロジェクトのセッションをステータス別に表示し、実行中のセッションはインタラクティブ、バッチ、推論、アップロードなどのタイプ別に表示します。

- **最近の自分のセッション:**
    最近作成したセッションを新しい順に一覧表示します。

- **私の総リソース使用量:**
    すべてのリソースグループとプロジェクトで自分のセッションが使用しているリソースを表示します。ドメイン、プロジェクト、キーペアなど複数の制限が同時に適用される場合は、**最も厳しい制限**が適用されます。

- **リソースグループの私のリソース:**
    カードに設定されたリソースグループにおけるリソース使用量と空き容量を表示します。

- **リソースグループの総リソース:**
    カードに設定されたリソースグループ全体の使用量と空き容量を要約表示します。グループに属するすべてのエージェントのデータを集計した値です。

- **エージェントの統計:**
    システム内のすべてのエージェントの総リソースを表示します。

- **ストレージボリュームごとの利用可能量:**
    各ストレージボリュームで利用可能な容量を表示します。利用可能量の設定に対応したストレージホストがない場合は、代わりに案内メッセージが表示されます。

- **自分のデプロイ:**
    自分のモデルデプロイをレプリカの状態とともに一覧表示します。

- **自分のアクティビティ:**
    カードに設定された期間に記録された自分の監査ログを一覧表示します。

:::note
**リソースグループの総リソース**と**エージェントの統計**のカードは、システム構成によって表示されない場合があります。
:::

プロジェクト管理者とスーパー管理者には、管理者メニューに専用の**ダッシュボード**があり、プロジェクトまたはクラスター全体を対象とするカードが表示されます。

## ダッシュボードレイアウトのカスタマイズ

ボードは特別なモードに切り替えなくても、いつでも並べ替えられます：

- **カードの移動**: カードのヘッダーをドラッグして、ボード上の位置を変更できます。
- **カードのサイズ変更**: カードの右下隅をドラッグしてサイズを調整できます。各カードにはコンテンツの可読性を確保するための最小サイズが設定されています。

**編集**ボタンをクリックすると編集サイドバーが開き、**閉じる**をクリックすると再び非表示になります。サイドバーにはそのページで提供されるすべてのカードがテーマ別に一覧表示されます。カードを選択するとボードに追加され、選択を解除するとボードから削除されます。

![](../images/dashboard_edit_mode.png)

配置はサーバー上の自分のアカウントに保存されるため、ログインするどのブラウザーでも同じ配置が使われます。配置をデフォルトに戻すには、編集サイドバー下部の**レイアウトを初期化**ボタンをクリックして確認します。レイアウトを初期化してもカスタムパネルは削除されません。

:::tip
WebUIの更新で新しいダッシュボードカードが追加された場合、保存済みの配置が
あっても、新しいカードは自動的にダッシュボードに表示されます。
:::

### カードの既定の設定

リソースグループや期間を使用するカードには、既定値を保存しておけます。編集サイドバーでそのカードの**カードの既定の設定**を開き、ボードを開いたときに適用する値を指定します。カードのヘッダーの選択メニューで変更した値は、表示中の間だけ適用されます。

### カスタムパネル

編集サイドバーにはカスタムパネルの一覧も表示されます。カスタムパネルは、選択したデータソースを指定した条件で絞り込んで表示します。パネルにはタイトルとデータのみが表示されるため、条件がわかるタイトルを付けることをおすすめします。

パネルを追加するには、サイドバーの**追加**ボタンをクリックします。パネルのダイアログには以下の項目があります。**パネル形式**と**データソース**は必須項目で、両方を選択しないとダイアログを送信できません。

- **データソース**: パネルに表示するデータソースです。**セッション**、**デプロイ**、**データストレージ選択**から選択します。
- **パネル形式**: データソースの表示方法です。**テーブル**、**カウント**、**チャート**から選択します。**セッション**データソースの場合は **グリッド** も選択できます。
- **タイトル**: パネルのタイトル（オプション）です。省略した場合はデータソース名が使用されます。
- **条件**: パネルに表示する項目を絞り込むプロパティフィルターです。

入力項目の下のライブプレビューには、現在の条件に一致する行が表示されます。プレビューで列をソートすると、そのソート順がパネルに適用されます。**追加**ボタンをクリックすると、パネルがボードに配置されます。

![](../images/dashboard_panel_modal.png)

**デプロイ**パネルは、デプロイページと同じテーブル（名前、状態、レプリカ概要、モデル、作成日時）を使用して、プロジェクトのモデルデプロイを一覧表示します。デプロイの名前をクリックすると、その詳細ページが開きます。

**チャート**を選択すると、条件に一致する項目をチャートとして表示します。**グループ比較**のチャートの種類（ドーナツ、円、棒、レーダー）は、**グループ化**で選んだプロパティごとに項目数を数えます。**作成数の推移**のチャートの種類（折れ線、面、縦棒）は、選択した期間を区切った各区間で作成された項目数を数えます。**テーブルも表示**をオンにすると、条件に一致する行がパネルのチャートの下に表示されます。

**グリッド**を選択すると、セッションリソースグリッドが表示されます。条件に一致する各セッションに割り当てられたリソースを、使用率に応じて色分けされたユニットセルとして表示します。セッションをクリックすると、テーブルで行をクリックしたときと同様に詳細ドロワーが開きます。グリッドは条件に一致するセッションのうち最大100件までを表示し、それを超える場合は件数の通知が表示されます。

グリッドの表示設定（リソース／カーネルモード、表示するリソースまたはメトリック、メモリ単位、レイアウト）は、パネルの追加／編集ダイアログのライブプレビューで指定し、パネルとともに保存されます。パネル自体にはこれらの設定を変更するコントロールがないため、別の表示にしたい場合はパネルをもう一つ追加してください。

:::note
**グリッド**は実験的機能です。**パネル形式**の選択肢に表示されるのは、[実験的特徴](#experimental-features)で**Session resource grid view** がオンになっている場合のみです。後でこの設定をオフにしても、作成済みのグリッドパネルは保存された設定を維持したまま、設定を再度オンにするまでセッションテーブルとして表示されます。
:::

パネルのデータソース、パネル形式、条件、タイトルを後から変更するには、サイドバーの該当パネルの横、またはボード上のパネルヘッダーにある鉛筆（**編集**）アイコンをクリックし、変更内容を保存します。パネルを削除するには、ゴミ箱（**削除**）アイコンをクリックし、確認ポップアップで承認します。

:::note
**セッション**および**デプロイ**パネルは現在のプロジェクトのデータを表示し、すべてのプロジェクトメンバーが利用できます。**データストレージ選択**パネルはスーパー管理者のみ利用できます。現在の権限で照会できないデータソースのパネルは、サイドバーの一覧には残りますが、ボードには表示されません。
:::

## 自動更新

ダッシュボードバーの更新コントロールで、すべてのカードの更新間隔を設定できます。**オフ**または5秒から10分の間隔を選択でき、コントロールをクリックするとすべてのカードをすぐに更新します。
