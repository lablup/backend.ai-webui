# 대시보드

**대시보드**는 로그인한 다음 처음 열리는 페이지로, 여러 개의 카드로 이루어져 있습니다. 맨 위의 카드들은 처음 자주 하는 작업으로 바로 가는 단축 카드입니다. 카드마다 작업 이름과 한 문장 설명, 그 작업을 시작하는 버튼이 있습니다.

- **인터랙티브 세션 생성:**
    **세션 시작**을 클릭하면 세션 런처가 열립니다. 런처에서 환경과 자원을 고른 다음 코드를 대화형으로 실행할 수 있습니다.

- **배치 세션 생성:**
    **세션 시작**을 클릭하면 세션 유형이 배치로 설정된 세션 런처가 열립니다. 입력한 명령을 끝까지 자동으로 실행하는 세션을 만들 때 사용합니다.

- **새 스토리지 폴더 생성하기:**
    **폴더 생성하기**를 클릭하면 세션에서 사용할 파일과 데이터를 보관할 스토리지 폴더를 만들 수 있습니다.

- **배포 시작:**
    **배포 생성**을 클릭하면 학습한 모델을 다른 사람이 사용할 수 있도록 서비스하는 배포를 만들 수 있습니다. 관리자가 모델 서빙을 활성화한 경우에만 표시됩니다.

- **URL 로 시작:**
    **지금 시작하기**를 클릭하면 Jupyter 노트북, GitHub 또는 GitLab 저장소, Hugging Face 모델을 URL 로 가져올 수 있습니다. [URL 로 시작](#start-from-url)을 참고하세요.

![](../images/dashboard.png)

그 아래의 카드는 현재 프로젝트의 세션, 자원 사용량, 최근 활동을 보여 줍니다.

- **나의 세션:**
    현재 프로젝트의 세션을 상태별로 보여 주고, 실행 중인 세션은 *Interactive*, *Batch*, *Inference*, *Upload* 등 유형별로 보여 줍니다.

- **내 최근 세션:**
    가장 최근에 생성한 세션을 최신순으로 나열합니다.

- **나의 총자원 사용량:**
    모든 자원 그룹과 프로젝트에서 내 세션이 사용 중인 자원량을 표시합니다. 도메인, 프로젝트, 키페어 등 여러 제한이 동시에 적용될 경우 **가장 엄격한 제한**이 적용됩니다.

- **자원 그룹 내 나의 자원:**
    카드에 설정된 자원 그룹에서 사용 중인 자원과 남은 자원을 표시합니다.

- **자원 그룹 내 총자원:**
    카드에 설정된 자원 그룹 전체의 사용량과 가용량을 요약하여 표시합니다. 그룹 내 모든 에이전트의 데이터를 합산해 계산된 값입니다.

- **에이전트 통계:**
    시스템에 있는 모든 에이전트의 총자원을 표시합니다.

- **스토리지 볼륨별 가용량:**
    각 스토리지 볼륨에서 사용할 수 있는 가용량을 표시합니다. 가용량 설정을 지원하는 스토리지 호스트가 없는 경우에는 대신 안내 문구가 표시됩니다.

- **내 배포:**
    내 모델 배포를 복제본 상태와 함께 나열합니다.

- **내 활동 이력:**
    카드에 설정된 기간 동안 기록된 내 감사 로그를 나열합니다.

:::note
**자원 그룹 내 총자원**과 **에이전트 통계** 카드는 시스템 구성에 따라 표시되지 않을 수 있습니다.
:::

프로젝트 관리자와 슈퍼 관리자에게는 관리자 메뉴에 별도의 **대시보드**가 제공되며, 프로젝트 또는 클러스터 전체를 대상으로 하는 카드가 표시됩니다.

## 대시보드 레이아웃 사용자화

보드는 별도의 모드로 전환하지 않아도 언제든지 재배치할 수 있습니다.

- **카드 이동**: 카드의 헤더를 드래그하여 보드 내에서 위치를 변경할 수 있습니다.
- **카드 크기 조정**: 카드의 우측 하단 모서리를 드래그하여 크기를 조정할 수 있습니다. 각 카드는 콘텐츠의 가독성을 보장하기 위한 최소 크기가 설정되어 있습니다.

**편집** 버튼을 클릭하면 편집 사이드바가 열리고, **닫기**를 클릭하면 다시 숨겨집니다. 사이드바에는 해당 페이지에서 제공하는 모든 카드가 주제별로 나열됩니다. 카드를 선택하면 보드에 추가되고, 선택을 해제하면 보드에서 제거됩니다.

![](../images/dashboard_edit_mode.png)

배치는 서버의 내 계정에 저장되므로, 로그인하는 모든 브라우저에서 동일하게 유지됩니다. 배치를 기본 상태로 되돌리려면 편집 사이드바 하단의 **기본 배치로 초기화** 버튼을 클릭한 뒤 확인합니다. 배치를 초기화해도 사용자 정의 패널은 삭제되지 않습니다.

:::tip
WebUI 업데이트로 새로운 대시보드 카드가 추가되면, 저장된 배치가 있더라도
새 카드가 대시보드에 자동으로 표시됩니다.
:::

### 카드 기본 설정

자원 그룹이나 기간을 사용하는 카드는 기본값을 저장해 둘 수 있습니다. 편집 사이드바에서 해당 카드의 **카드 기본 설정**을 열어 보드를 열 때 적용할 값을 지정하세요. 카드 헤더의 선택 메뉴에서 바꾼 값은 현재 보고 있는 동안에만 적용됩니다.

### 사용자 정의 패널

편집 사이드바에는 사용자 정의 패널 목록도 함께 표시됩니다. 사용자 정의 패널은 선택한 데이터 소스를 지정한 조건으로 좁혀 보여 줍니다. 패널에는 제목과 데이터만 표시되므로, 조건을 설명하는 제목을 지정하는 것이 좋습니다.

패널을 추가하려면 사이드바의 **추가** 버튼을 클릭합니다. 패널 대화 상자는 다음 항목으로 구성됩니다. **패널 형식**과 **데이터 소스**는 필수 항목이며, 둘 다 선택해야 대화 상자를 제출할 수 있습니다.

- **데이터 소스**: 패널에 표시할 데이터 소스입니다. **세션**, **배포**, **데이터 & 폴더** 중에서 선택합니다.
- **패널 형식**: 데이터 소스를 표시하는 방식입니다. **테이블**, **카운트**, **차트** 중에서 선택하며, **세션** 데이터 소스인 경우 **그리드**도 선택할 수 있습니다.
- **제목**: 패널 제목(선택 사항)입니다. 입력하지 않으면 데이터 소스 이름이 사용됩니다.
- **조건**: 패널에 표시할 항목을 좁히는 속성 필터입니다.

입력 항목 아래의 실시간 미리 보기에는 현재 조건과 일치하는 행이 표시됩니다. 미리 보기에서 열을 정렬하면 해당 정렬 순서가 패널에 적용됩니다. **추가** 버튼을 클릭하면 패널이 보드에 추가됩니다.

![](../images/dashboard_panel_modal.png)

**배포** 패널은 배포 페이지와 동일한 테이블(이름, 상태, 복제본 요약, 모델, 생성일)을 사용해 현재 프로젝트의 모델 배포를 나열합니다. 배포 이름을 클릭하면 해당 배포의 상세 페이지가 열립니다.

**차트**를 선택하면 조건에 일치하는 항목을 차트로 보여 줍니다. **묶음 비교** 차트 형식(도넛, 파이, 막대, 레이더)은 **묶는 기준**으로 고른 속성별로 항목 수를 셉니다. **생성 추이** 차트 형식(선, 영역, 세로 막대)은 선택한 기간을 나눈 구간마다 새로 만들어진 항목 수를 셉니다. **테이블 함께 보기**를 켜면 조건에 일치하는 행이 패널의 차트 아래에 함께 표시됩니다.

**그리드**를 선택하면 세션 리소스 그리드가 표시됩니다. 조건에 일치하는 각 세션에 할당된 자원을 사용률에 따라 색이 다른 유닛 셀로 보여 줍니다. 세션을 클릭하면 테이블에서 행을 클릭했을 때와 마찬가지로 세부 정보 드로어가 열립니다. 그리드는 조건에 일치하는 세션 중 최대 100개까지만 표시하며, 그보다 많은 경우 안내 문구가 표시됩니다.

그리드의 표시 설정(리소스/커널 모드, 표시할 자원 또는 메트릭, 메모리 단위, 배치 방식)은 패널 추가/수정 대화 상자의 실시간 미리 보기에서 지정하며 패널과 함께 저장됩니다. 패널 자체에는 이 설정을 바꿀 수 있는 컨트롤이 없으므로, 다른 보기가 필요하면 패널을 하나 더 추가하세요.

:::note
**그리드**는 실험적 기능입니다. **패널 형식** 선택 목록에는 [실험적 기능](#experimental-features)에서 **세션 리소스 그리드 뷰**가 켜져 있을 때만 표시됩니다. 이후 이 설정을 끄더라도 이미 만든 그리드 패널은 저장된 설정을 유지한 채, 설정을 다시 켤 때까지 세션 테이블로 표시됩니다.
:::

패널의 데이터 소스, 패널 형식, 조건, 제목을 나중에 변경하려면 사이드바에서 해당 패널 옆의 연필(**수정**) 아이콘 또는 보드에 표시된 패널 헤더의 아이콘을 클릭한 뒤 변경 내용을 저장합니다. 패널을 제거하려면 휴지통(**삭제**) 아이콘을 클릭하고 확인 팝업에서 승인합니다.

:::note
**세션** 및 **배포** 패널은 현재 프로젝트의 데이터를 보여 주며 모든 프로젝트 구성원이 사용할 수 있습니다. **데이터 & 폴더** 패널은 슈퍼 관리자만 사용할 수 있습니다. 현재 권한으로 조회할 수 없는 데이터 소스의 패널은 사이드바 목록에는 남아 있지만 보드에는 표시되지 않습니다.
:::

## 자동 새로고침

대시보드 바의 새로고침 컨트롤에서 모든 카드의 새로고침 주기를 지정할 수 있습니다. **끄기** 또는 5초에서 10분 사이의 주기를 선택할 수 있으며, 컨트롤을 클릭하면 모든 카드를 즉시 새로고침합니다.

<a id="start-from-url"></a>

## URL 로 시작

**URL 로 시작** 대화상자에는 가져오기 원본별로 **노트북 가져오기**,
**GitHub 저장소 가져오기**, **GitLab 저장소 가져오기** 탭이 있습니다. 실험적 기능인
Hugging Face 가져오기를 활성화하면 **Hugging Face 모델 가져오기** 탭이 추가로
표시됩니다.

### 노트북 가져오기

![=800px](../images/start_from_url_notebook.png)

1. **가져올 노트북 URL** 필드에 Jupyter Notebook URL(`.ipynb`으로 끝나는)을
   입력합니다
2. **가져와서 실행** 버튼을 클릭하면 자동으로 세션이 생성되고 Jupyter에서
   노트북이 열립니다

   버튼 옆의 드롭다운 화살표를 클릭하고 **설정 후 실행**을 선택하면 실행
   전에 세션 환경을 사용자화할 수 있습니다.

:::note
노트북은 연산 세션 내부에서 다운로드되므로(부트스트랩 스크립트가 `curl -O <url>`을
실행합니다), 입력한 URL은 연산 세션에서 접근할 수 있어야 합니다. `localhost`나
`127.0.0.1` 같은 로컬 주소는 사용자의 컴퓨터가 아니라 세션 컨테이너 자신을 가리키므로
동작하지 않습니다. 연산 세션에서 접근 가능한 URL을 입력하세요.
:::

:::note
팝업 차단기를 해제해야 실행 중인 노트북 창을 바로 확인할 수 있습니다. 또한,
세션을 실행할 자원이 충분하지 않은 경우 가져온 노트북이 실행되지 않습니다.
:::

탭 하단에서 "Run on Backend.AI" 뱃지 코드를 생성할 수 있습니다. HTML 또는
Markdown 뱃지 코드를 복사하여 프로젝트 문서에 바로 실행 링크를 삽입할 수
있습니다.

:::note
뱃지 코드를 생성하기 전에 로그인되어 있어야 합니다. 그렇지 않으면 먼저
로그인한 후 다시 시도해 주십시오.
:::

### GitHub 저장소 가져오기

![=800px](../images/start_from_url_github.png)

1. **GitHub 주소** 필드에 유효한 GitHub 저장소 URL을 입력합니다
2. 저장소가 저장될 **스토리지 호스트**를 선택합니다
3. 필요한 경우 **폴더 사용 방식**(일반 또는 모델)을 설정합니다
4. **가져오기** 버튼을 클릭하여 저장소를 새 스토리지 폴더로 복제합니다

가져온 저장소는 스토리지 폴더로 변환되며, 세션 시작 시 마운트할 수 있습니다.

### GitLab 저장소 가져오기

![=800px](../images/start_from_url_gitlab.png)

1. **GitLab 주소** 필드에 유효한 GitLab 저장소 URL을 입력합니다
2. 필요한 경우 **GitLab 브랜치 이름**을 지정합니다 (기본값: `master`)
3. 저장소가 저장될 **스토리지 호스트**를 선택합니다
4. 필요한 경우 **폴더 사용 방식**(일반 또는 모델)을 설정합니다
5. **가져오기** 버튼을 클릭하여 저장소를 새 스토리지 폴더로 복제합니다

### Hugging Face 모델 가져오기

**Hugging Face 모델 가져오기** 탭에서는 Hugging Face의 모델을 모델 폴더로
다운로드할 수 있습니다. 다운로드한 모델은 이후 연산 세션에 마운트하거나 배포로
서비스할 수 있습니다.

:::warning[실험적 기능]
이 탭은 [사용자 설정](#user-settings) 페이지의 **실험적 기능** 항목에서
**Hugging Face에서 가져오기**를 활성화해야 표시됩니다. 실험적 기능은 향후
업데이트에서 변경되거나 제거될 수 있습니다.
:::

![=800px](../images/start_from_url_huggingface.png)

1. **Hugging Face 모델 URL 또는 ID** 필드에 모델을 입력합니다.
   `https://huggingface.co/openai/gpt-oss-20b`와 같은 모델 페이지 URL과
   `openai/gpt-oss-20b`와 같은 모델 ID를 모두 사용할 수 있습니다. 데이터셋,
   스페이스 등 모델이 아닌 페이지의 주소는 허용되지 않습니다.

   필드에 유효한 모델을 입력하면 잠시 후 대화상자가 Hugging Face에서 모델을
   조회합니다. 확인하는 동안 로딩 표시가 나타나며, 가져오기를 시작하기 전에
   필드 아래에 미리보기 카드를 표시합니다. 카드에는 Hugging Face 페이지로
   연결되는 모델 ID 링크, 모델의 작업 및 라이브러리 태그, 크기,
   수정일이 표시됩니다.

2. 필요한 경우 **리비전**에 다운로드할 모델 저장소의 브랜치, 태그 또는 커밋을
   입력합니다. 비워 두면 기본 리비전을 다운로드하며, 입력한 주소에 리비전이
   포함되어 있으면 해당 리비전을 사용합니다.
3. 필요한 경우 **Hugging Face 토큰**을 입력합니다. 접근이 제한되었거나 비공개인
   모델에는 토큰이 필요합니다.
4. 다운로드할 **모델 폴더**를 선택합니다. 필드 아래의 안내 문구처럼 현재
   프로젝트에서 쓰기 권한으로 마운트할 수 있는 모델 폴더만 표시됩니다.
   다운로드 세션이 폴더에 파일을 쓰기 때문에 읽기 전용으로만 마운트할 수 있는
   폴더는 제외됩니다. 선택기 옆의 버튼으로 선택한 폴더 열기, 새 모델 폴더 생성,
   목록 새로고침을 수행할 수 있습니다.
5. **모델을 폴더로 다운로드** 버튼을 클릭합니다.

대화상자가 닫히고 다운로드를 수행하는 배치 세션이 시작됩니다. 다운로드는 해당
세션 내부에서 진행되므로 세션 페이지에서 진행 상황을 확인할 수 있으며, 세션이
성공적으로 종료되면 모델을 사용할 수 있습니다. 세션이 실패하면 다운로드가
완료되지 않은 것이므로 모델을 사용할 수 없습니다.

모델은 선택한 폴더 안에 모델 이름으로 만들어진 하위 폴더에 저장됩니다. 예를 들어
`openai/gpt-oss-20b`는 `gpt-oss-20b/`에 다운로드됩니다. 따라서 하나의 모델 폴더에
여러 모델을 함께 보관할 수 있습니다.

:::warning
토큰은 다운로드 세션에 `HF_TOKEN` 환경 변수로 전달되며 관리자가 확인할 수
있습니다. 읽기 전용 토큰을 사용하십시오.
:::

:::note
이 탭은 모델 폴더로 다운로드하므로, 배포 기능이 활성화된 계정에서만 사용할 수
있습니다. 크기가 큰 모델은 다운로드에 오랜 시간이 걸리며 대상 폴더의 저장 용량을
소모합니다.
:::
