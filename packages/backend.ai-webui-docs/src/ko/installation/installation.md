# 설치

Backend.AI WebUI는 두 가지 형태로 사용할 수 있습니다. 관리자가 제공하는 별도의 웹 주소에 접속하여 웹 서비스 형태로 사용하거나, 별도의 설치가 필요 없는 단독 실행 파일 형태의 앱으로 사용할 수 있습니다.

웹 서비스 형태의 WebUI는 플랫폼 의존적인 데스크톱 앱을 따로 설치할 필요 없이 최신 웹 브라우저만 있으면 됩니다.

- 지원 브라우저: Chrome 123 이상, Edge 123 이상, Safari 17.5 이상, Firefox 125 이상
- 요구사항: 웹 브라우저를 구동할 수 있는 머신 (2 코어, 4 GiB 메모리)


:::note
지원 버전보다 오래된 브라우저로 WebUI에 접속하면 로딩 화면에 지원하지 않는 브라우저라는 메시지와 지원 브라우저 목록이 표시되고 WebUI가 로드되지 않습니다. 브라우저를 업데이트하거나 지원 브라우저 중 하나를 사용하십시오. 그 브라우저에서 그래도 WebUI를 사용하려면 메시지 아래의 **그래도 이용하기**를 클릭한 뒤 확인 대화 상자에서 **계속 이용하기**를 클릭하십시오. 정상 동작은 보장되지 않으며, 새 탭에서 열거나 로그아웃하면 메시지가 다시 표시됩니다.

마이크로소프트 인터넷 익스플로러는 더 이상 지원되지 않으며 최신 브라우저 기능을 지원하지 않기 때문에 지원 대상에서 제외되었습니다.

WebUI 단독 실행 파일 앱은 자체 브라우저 엔진을 포함하므로 이 검사가 적용되지 않습니다.
:::

WebUI 단독 실행 파일 앱은 다음 링크에서 다운로드할 수 있습니다:
https://github.com/lablup/backend.ai-webui/releases


:::note
운영체제의 보안 설정에 따라 설치 프로그램이 서명되지 않은 실행 파일로 인식될 수 있습니다. 권한 확인이 필요할 수 있습니다.
:::
