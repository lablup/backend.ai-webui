# Architecture overview

This document indexes the ADRs (Architecture Decision Records) in force. Each ADR file under `docs/adr/` is
the authority, and this table adds no new interpretation. An ADR that has landed on `main` is a decision in
force, and the code follows it.
`ARCHITECTURE.ko.md` and each ADR's `.ko.md` file are the Korean translations; the English files are the authority (ADR 0018).

## Writing a new ADR

`.claude/rules/adr.md` decides when an ADR is needed, and the `.claude/skills/adr-writing/` skill fixes the
file name, title, section layout, sentence rules, and the checks before landing. The ADR file, its `.ko.md`
companion, its row in this table and in `ARCHITECTURE.ko.md`, and the code that follows the decision land in one PR.
